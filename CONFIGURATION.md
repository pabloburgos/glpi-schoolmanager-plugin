# Configuration from GLPI

1. Install and activate the plugin.
2. Log in as Super-Admin.
3. Open **Tools → GLPI School Manager → Initial setup**.
4. Configure name, language, modules, palette, logo, buildings, floors and rooms.
5. Upload the required plans per building/floor.
6. Save changes.

Settings are stored in `plugins/schoolmanager/data/config.php` and uploaded files in `plugins/schoolmanager/maps/`.
