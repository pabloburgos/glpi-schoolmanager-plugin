## What changed from the earlier prototype?

- Non-software license references were removed from the software project.
- Plugin metadata now declares **GPLv3+ / GPL-3.0-or-later**.
- GitHub documentation and contribution files now point to the same canonical license file.
- Duplicate top-level license files were removed to keep the GitHub repository cleaner.
