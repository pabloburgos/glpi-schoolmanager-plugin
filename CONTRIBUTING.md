#  Contributing

Thank you for your interest in contributing to **School Manager**.

## Ways to contribute

You can help with:

-  Bug reports
-  Feature proposals
-  Translation fixes
-  Documentation improvements
-  UI/UX improvements
-  GLPI compatibility testing
-  Accessibility improvements

## Contribution rules

- Keep the plugin folder name as `schoolmanager`.
- Do not hardcode school names or private internal data.
- Keep user-facing text translatable.
- Test changes in GLPI before opening a pull request.
- Preserve compatibility with **GLPI 10 / GLPI 11** where possible.
- If a change affects behaviour or setup, update the documentation too.

## Translation contributions

Spanish is the main reviewed language. English support is available and can still benefit from improvements.

When checking translations, review:

- Page titles
- Buttons
- Placeholders
- Form labels
- Help text
- Empty states
- Error messages

## Pull request checklist

- [ ] I tested the plugin in GLPI.
- [ ] I cleared GLPI cache.
- [ ] I refreshed browser cache.
- [ ] I checked Spanish texts.
- [ ] I checked English texts.
- [ ] I did not include private data.
- [ ] I updated documentation if needed.
